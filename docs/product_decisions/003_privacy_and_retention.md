# 诺亚方舟数据与隐私说明

版本：0.1。更新日期：2026-10-03。

适用范围：当前开发和内部测试版本。本文说明现有功能的数据处理、
保留与删除规则及应用内告知，不代表已开放正式账号同步或云端 AI 服务。
正式公开发布前仍须完成本文末尾列出的发布事项。

## 使用选择与数据用途

- 不创建账号也能使用本地文字记录、录音和本地转写。
- 记录内容、标题、标签、收藏状态和时间用于本地展示、搜索和整理。
- 录音用于用户主动选择的播放与本地转写；转写文本用于整理闪念。
- 昵称、邮箱和密码用于用户主动使用的账号功能；密码以哈希形式存入服务器。
- 登录、同步、云端 AI 处理和公开分享是分别选择的功能。当前未启用同步
  或云端 AI，登录不会自动上传本地记录和录音。
- 本地 SQLite 和导出的 JSON 未由应用单独加密；请保护设备及导出副本。

## 当前数据处理

| 数据或操作 | 当前处理方式 |
|---|---|
| 正式记录 | 保存在本机 SQLite，不会因登录自动上传 |
| 原始录音 | 保存在本机，供播放和本地转写使用 |
| 语音转写 | 使用设备上的 sherpa-onnx 模型处理 |
| 模型下载 | 从 Hugging Face 下载模型与词表，需要联网 |
| 账号功能 | 注册、登录等操作会向配置的后端发送必要数据 |
| 导出备份 | 用户主动生成，文件由用户保管 |
| 删除账号 | 删除服务器账号及关联数据，保留本地记录、录音和导出文件 |

## 保留与删除规则

以下描述当前开发和测试版本的实际行为。

| 数据 | 保留与删除方式 |
|---|---|
| 本地正式记录 | 没有自动过期时间，由用户主动删除 |
| 闪念草稿、转写文本和原始录音 | 没有自动过期时间；成功删除闪念时，删除该草稿及其原始录音 |
| 已转换为正式记录的闪念 | 转换后仍保留草稿和原始录音；删除正式记录只解除关联，不删除草稿和录音 |
| 本地转写模型 | 下载后保留在应用目录，目前没有应用内删除模型入口 |
| 用户导出的 JSON 备份 | 当前仅包含正式记录，不包含原始录音；用户自行管理保存、分享及删除 |
| 服务器账号及关联数据 | 保留至用户成功删除账号或测试环境人工清理；当前没有按账号闲置时间自动清理的机制；删除账号会删除当前数据库中的账号及关联记录、验证令牌、重置令牌和刷新会话 |
| 本机登录凭据 | 使用平台安全存储；成功退出登录或删除账号时清除本机凭据 |
| 服务端历史令牌记录 | 当前没有定时清理机制，保留至关联账号删除或测试环境人工清理；过期、使用或撤销不等于数据库记录已删除 |
| PostgreSQL 测试环境备份 | 按运维规则保留最近七组成功的备份与清单，以及最新的已验证恢复报告；核验新备份后人工清理旧副本，目前没有自动清理 |
| 服务器日志 | 应用输出至进程标准输出，不维护日志文件或定时清理任务；托管平台的日志查询范围按套餐执行，具体配置和平台内部删除流程尚未核实 |

### 认证凭据的有效期

- 访问令牌：默认 15 分钟。
- 刷新令牌家族：默认从创建起 30 天，轮换不会延长家族期限。
- 邮箱验证令牌：24 小时。
- 密码重置令牌：默认 60 分钟。

可配置的有效期以部署设置为准。有效期决定凭据是否可用，
不代表数据库中的对应记录会自动删除。

### 删除的范围

- 删除服务器账号不会清空本机记录、闪念、原始录音或导出文件。
- 删除闪念不会删除此前由它转换出的正式记录。
- 删除当前数据不会修改此前生成的备份；旧备份可能仍包含已删除的数据。
- 已保存或分享到其他位置的导出文件，需要用户在相应位置另行删除。
- 清除应用数据或卸载应用可能删除本地数据，不能替代服务器账号删除。

### 正式发布前待落实

当前规则只适用于开发测试。正式服务的账号、历史令牌、日志与备份

## 第三方服务与联网行为

以下根据当前代码和项目部署文档说明。
实际后端地址由构建时的 API_BASE_URL 配置决定。

| 服务或组件 | 用途、触发条件与数据范围 |
|---|---|
| Hugging Face | 用户触发模型下载时，获取模型与词表；下载服务可接收到 IP 地址和文件请求。当前下载请求不携带录音、转写文本、本地记录或应用账号凭据 |
| sherpa-onnx / SenseVoice | 模型安装后在设备上处理录音，生成转写文本；当前转写流程没有调用云端识别服务 |
| 应用后端 | 注册、登录、刷新会话、验证、重置密码和删除账号等操作，会按需发送昵称、邮箱、密码或相应令牌；登录不会自动上传本地记录和录音 |
| Railway 测试部署 | 项目部署文档记录其托管实验 API 和 PostgreSQL；连接该后端时，请求由托管服务处理。测试环境仅用于一次性测试账号和测试记录 |
| 系统分享及用户选择的目标应用 | 主动导出备份时，通过系统分享功能交付 JSON 文件；用户选择的应用或保存位置可能接收文件，后续处理由该应用或服务决定 |
| 邮件服务 | 当前没有接入真实邮件服务商；假发送器只在后端进程内保存测试消息，不向外部发送邮件 |
| JSONPlaceholder 测试接口 | 代码保留了获取示例数据的方法，当前应用界面未发现调用入口；该方法若被调用，会发起外部 GET 请求，不携带本地记录或账号凭据 |

### 日志与其他数据处理

- 当前应用与后端代码未接入广告 SDK、第三方行为分析 SDK
  或云端 AI 内容处理服务。
- 应用结构化请求日志仅记录时间、事件、请求 ID、方法、
  路由模板、状态码、耗时和错误码等允许字段，
  不记录请求正文、密码、原始令牌或私人记录内容。
- 托管平台的网络日志和保留规则，需要与应用自身日志分别核实。
- Android 已配置 `allowBackup=false`，并通过旧版备份规则及 Android 12+
  数据提取规则排除所有应用备份域的云备份与设备间迁移。
  排除范围包含本地数据库、录音、模型、应用文件和登录凭据。
  已导出到其他应用或公共位置的文件由用户自行管理。
  配置不清除旧版本可能产生的系统副本；厂商迁移工具及系统的
  跨平台迁移行为仍需真机验证，不承诺所有厂商工具均遵循这些规则。

## 录音、模型下载与转写的告知规则

采用功能附近的常驻说明和用户主动操作；联网下载使用确认弹窗。

### 录音

- 录音区域常驻说明本地保存、不会由应用上传、后台继续录制以及停止方法。
- 用户点击“开始录音”后才申请麦克风和必要的通知权限并启动录音；
  拒绝权限不启动录音，不影响本地文字记录。
- 录音期间显示状态、时长和“停止并保存”；Android 后台录音显示前台服务通知。
- 停止并保存后生成草稿，不自动转写。
- 启动应用或切换页面不新建录音；重新连接已有录音时显示正在录制状态。

### 模型下载

- 缺少模型时，先说明来源为 Hugging Face、约 228 MB、流量与空间占用、
  IP 地址和文件请求可被下载服务接收，录音和记录不发送给下载服务。
- 确认按钮为“下载并转写”，表示下载成功后继续所选录音的本地转写。
- 取消或关闭弹窗时不下载、不转写当前所选录音；不自动取消其他已排队任务。
- 下载失败或页面关闭时不继续当前转写，原始录音保留。

### 本地转写

- 草稿操作区常驻说明本地处理、首次下载联网和原始录音继续保留。
- 用户点击“开始转写”或“重新转写”后提交所选草稿；模型安装后无需云端识别服务。
- 成功和失败均保留原始录音，由用户另行删除。
- 排队任务支持“取消排队”；正在执行的任务当前不支持中途取消，也不能立即删除。
